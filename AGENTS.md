# ReviewTrust engineering guidance

Build an evidence-based electronics review-pattern analyzer, never an authenticity authority. Stack: Next.js App Router/React/TypeScript/Tailwind and Python FastAPI/Pydantic/Uvicorn. Offline ML only when justified; no database, accounts, paid LLM, URL fetching or browser extension in v1.

SPEC.md owns contracts, scoring, evidence definitions and acceptance criteria. docs/THREAT_MODEL.md owns proposed controls. docs/DECISIONS.md records tradeoffs. Numeric scoring is experimental; missing evidence is never low risk; no confidence level without validation. No review names, raw-body logs or persisted uploads. Treat all input as untrusted.

Prefer small pure analysis functions, explicit typed API contracts, deterministic evidence and native/standard-library features. Server limits and validation are authoritative. Add dependencies only for concrete needs. Review methodology changes with a version bump and regression fixtures.

Foundation: `web/app/page.tsx` stays synchronous and composes the client Analyzer; browser input/results are implemented. FastAPI serves GET / development status, GET /health and POST /v1/analyze (JSON), /v1/analyze/csv (multipart). `ml/` holds the offline source audit, labelling rubric and bounded synthetic audit/split tool; no real dataset is admitted. Runtimes: Node 24 and Python 3.12. Install with `npm --prefix web ci` and the pinned `api/requirements-dev.txt` in `api/.venv`. Do not add ML dependencies before justified evaluation work.

Input contracts live in `api/app/schemas.py`; use `parse_json`/`parse_csv` from `api/app/ingestion.py` for untrusted bytes and `ReviewInputError` for safe public details. Never expose raw Pydantic errors or submitted unknown keys. See docs/INPUT_VALIDATION.md. Decimal rating bounds are checked before float conversion. Keep duplicate rows and request-local references. Library records are raw; `analysis.py` masks common emails/phones before matching/output and `security.py` enforces HTTP boundaries. Masking is incomplete; the UI must request removal of personal information and render returned review text safely.
